# Неполный комплект: вывести механизм, а не инструкцию

Положение автора (2026-09-03): «мы не только инструкцию, мы выводим
механизм; комплект не полон». Проверено прогоном, а не рассуждением.

## 1. Что сделано

`tools/make_kit.py` собирает из полного набора **публичный комплект**, из
которого выведен механизм сборки:

* между кусками вырезан **зазор**: соседние куски не имеют общих пикселей,
  а вырезанные полосы **не лежат в комплекте нигде**;
* часть кусков удержана, вразброс — как blacklisting у Google Books;
* имена по хешу содержимого, координат в них нет;
* публичный указатель перечисляет только опознаватели: ни x, ни y, ни
  соседей;
* текстовый слой наружу не идёт вовсе — там собирать нечего.

Полный набор с нахлёстом, координатами и текстом остаётся в приватной зоне.

## 2. Замер: механизм действительно выведен

`tools/kit_assembly_test.py` на комплекте (зазор 96 px, удержано 25 %,
масштаб 0.5), страница 7 схемы Е7-12:

```
фрагментов 174, сравнений 60204, подбор 2.1 с
  стык «справа»: найдено 57 с невязкой < 1.0, из них ВЕРНЫХ 0
  стык «снизу» : найдено 56 с невязкой < 1.0, из них ВЕРНЫХ 0
```

Против полного набора, где верных стыков было 71 и 69, а побайтных
совпадений — 103 из 104. **Ни одного верного стыка.** Оставшиеся нулевые
невязки — совпадения пустых белых краёв чертежа друг с другом; сведений о
взаимном расположении они не несут.

Вывод замером: **зазор снимает самособираемость, чего изъятие индекса не
делало.** Положение автора подтверждено.

## 3. Но одного этого мало: нужна доля, а не только несобираемость

Право спрашивает не «собирается ли», а «воспроизведена ли существенная
часть». Поэтому `make_kit.py` печатает **долю площади произведения,
оставшуюся в комплекте**. Три прогона на том же документе:

| зазор | удержано | масштаб | кусков | **площадь произведения в комплекте** |
|---:|---:|---:|---:|---:|
| 96 | 25 % | 0.5 | 230 из 300 | **61.6 %** |
| 256 | 60 % | 0.4 | 124 из 300 | **12.6 %** |
| 384 | 75 % | 0.4 | 79 из 300 | **2.0 %** |

Мерка для сравнения — числа из решения по Google Books: 22 % книги закрыты
навсегда, исследователи истца за недели работы достали **не более 16 %**.

Первая строка — 61.6 % — это по-прежнему существенная часть, и никакая
несобираемость этого не лечит. **Вторая строка проходит под планку Google
Books.** Это и есть искомая настройка, а не первая попавшаяся.

Цена названа честно: при 12.6 % комплект перестаёт быть корпусом для
чтения. Он годится показать, что документ есть, и дать выборочные узлы —
не более. Полное чтение остаётся в приватной зоне, и именно там оно и
должно быть по доводу о безразличии места
([`ИНДЕКС-В-ПРИВАТЕ.md`](ИНДЕКС-В-ПРИВАТЕ.md) §4).

## 4. Принцип торрента: разобрано и отклонено

Предложение автора попробовать «принцип торрента» — раздать куски так,
чтобы целого не было ни у кого — проверено по практике.

**Это худшая из возможных опор.** BitTorrent — самая засуженная
архитектура распространения за последние двадцать лет, и довод «у меня был
только кусок» там проигран многократно. В делах Malibu Media суды
отклоняли ссылку на de minimis при раздаче частей файлов и присуждали
статутные убытки: в одном из дел — 16 500 долларов за одиннадцать
произведений при раздаче лишь частей. Общая планка de minimis к тому же
узкая: использование не признаётся ничтожным, если оно «so meager and
fragmentary that the average audience would not recognize the
appropriation»; Второй округ в 2026 году сузил её ещё.

Есть и содержательная разница, которая решает дело:

| | торрент | наш неполный комплект |
|---|---|---|
| где произведение | **100 % есть в рое**, только разложено по держателям | **87.4 % отсутствует** в публичной зоне вообще |
| роль участника | каждый раздаёт часть **целого, которое собирается** | часть произведения не существует ни у кого снаружи |
| практика | десять лет решений против | опирается на Google Books и HathiTrust |

Торрент делит **хранение** целого; неполный комплект уничтожает **часть
самого материала** на публичной стороне. Первое — распространение
произведения по частям, второе — не распространение произведения. Смешение
этих двух вещей и есть то место, где рассуждение обычно ломается.

Поэтому: как способ **раздачи между своими приватными узлами** торрент
безразличен и допустим; как правовое основание публичной раздачи — нет.

## 5. Что осталось несделанным

* Пофайловый разбор правового статуса 125 файлов. Без него неизвестно,
  каким документам комплект вообще нужен: свободному по статусу материалу
  дробление не требуется, его публикуют целиком.
* Настройка `--gap/--withhold/--scale` подобрана на **одном** документе.
  Доля площади зависит от размера страницы и сетки; для каждого разряда
  материала её надо мерить отдельно, а не переносить.
* Замер несобираемости сделан на одной странице из 104 фрагментов.
  Прогон на всём корпусе не выполнялся.

## Источники

* Числа Google Books — `МАШИНОКОМПЛЕКТ.md` §4 (решение 804 F.3d 202).
* Практика по раздаче частей через BitTorrent и de minimis — обзоры дел

  решения в этой сессии не открывались, и это отмечено как неполнота.
