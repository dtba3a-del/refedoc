# Замер OCR, 2026-09-05 — публичная половина

Порядок выбора настроек, установленный распоряжением автора:
**механический профиль → зрение → замеренный перебор.** Tesseract без
настроек производит мусор; зрение по пробам часто решает задачу
удовлетворительно; перебор проверяет зрение числом.

| Файл | Что это |
|---|---|
| `ocr_profile.json` | механика: 6 проб из 85 страниц, плотность краски, высота строки, оценка колонок — страницы разошлись на 4 группы |
| `выбор-зрением.json` | что выбрало зрение по пробам, с основанием каждого параметра |
| `ocr_sweep.json` | перебор 6 комбинаций на стр. 34: знаков, слов, доля мусора |
| `настройки-до-разбора.json` | отправная точка, от которой считался выигрыш |

Рабочие настройки — `refedoc/tools/ocr_settings/ocr_settings.json`.

## Где перебор поправил зрение

Зрение назначило `rus+eng`: в тексте `Cx`, `Lx`, `kHz`, `pF`. Довод
выглядел верным и оказался неверным — движок с двумя алфавитами
подставляет латинские двойники кириллицы. Замер: мусора 0.232 против
0.253, то есть **один язык лучше**. Это и есть причина, по которой
перебор идёт после зрения, а не вместо него.

## Где зрение увидело то, чего механика не видит

Проба стр. 51 — **разворот**: две книжные страницы с корешком.
Механический профиль назвал это «две колонки», и распознаватель без
резки тянул строку через корешок. Резка вернула 32 % текста.

## Выбор объёма против чистоты

`psm 4` даёт мусора меньше (0.209 против 0.232), но текста на 39 %
меньше. Слой поисковый — выбран объём, `psm 6`. Выбор назван здесь,
чтобы его можно было пересмотреть, когда потребитель слоя другой.
