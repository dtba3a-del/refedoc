Что делает скрипт
Один проход по директории с исходными изображениями создаёт три слоя данных:
Превью (thumbs/) — пропорционально уменьшенная копия до заданного максимума (по умолчанию 1024 px по длинной стороне). Достаточно для общего обзора схемы целиком.
Фрагменты с overlap (tiles_overlap/) — оригинал нарезается на фрагменты заданного размера с нахлёстом. Крайние фрагменты сдвигаются к границе изображения, так что ничего не теряется. Каждый фрагмент в индексе содержит координаты x, y, w, h, толщину нахлёста с каждой стороны и индексы соседей (top/bottom/left/right) для точного совмещения.
Чистые фрагменты (tiles_clean/) — опционально, при флаге --clean. Ровная сетка без overlap, последний ряд/столбец может быть меньше tile_size. Полезно для сопоставления с другими выборками или OCR.
Итоговый index.json содержит дерево: список изображений → пути к оригиналу, превью, массивы фрагментов с метаданными.

Таблица





| Проблема                           | Решение                                                      |
| :--------------------------------- | :----------------------------------------------------------- |
| Обязательный аргумент `input`      | Сделан **опциональным** (`nargs="?"`).                       |
| Не ясно, где искать картинки       | Если `input` не указан, скрипт берёт **папку, в которой сам лежит** (`Path(__file__).parent`). |
| Не ясно, куда складывать результат | Выходная папка по умолчанию — `sliced_output` **внутри той же папки**, где находится скрипт. |

### Как теперь запускать на Windows 11

**Просто положить в папку с картинками и запустить** (самый удобный способ):

cmd



```cmd
python scheme_slicer.py
```

Результат появится в подпапке `sliced_output` рядом со скриптом.

**С параметрами** (всё равно без указания пути):

cmd



```cmd
python scheme_slicer.py --tile-size 1536 --overlap 64 --clean --format png
```

**Если нужно обработать другую папку** — путь по-прежнему можно указать явно:

cmd



```cmd
python scheme_slicer.py "C:\Users\Name\Pictures\Schemes" --output "D:\Result"
```

**Если скрипт лежит отдельно, а запускать нужно из текущей папки cmd**:

cmd



```cmd
python C:\Tools\scheme_slicer.py --use-cwd
```

Флаг `--use-cwd` заставит скрипт работать с текущей директорией (где открыт терминал), а не с папкой, где находится сам скрипт.

Примеры запуска
Базовый вариант — превью 1024, фрагменты 1024, overlap 64 px, формат PNG:
bash
python scheme_slicer.py
Минимальный overlap (2–3 px) и крупные фрагменты — если требуется максимально точная стыковка с минимальным дублированием:
bash
python scheme_slicer.py  --output /out --tile-size 1536 --overlap 3
С генерацией чистых фрагментов и превью 512 (для быстрого просмотра ИИ):
bash
python scheme_slicer.py--output ./out --thumb-size 512 --clean --format png
Проверка плана без записи файлов:
bash
python scheme_slicer.py--dry-run --tile-size 2048 --overlap 128

 по параметрам для схем
Таблица
Параметр	Рекомендация	Пояснение
--tile-size	1024 или 1536	2048 — только если контекст позволяет.
--overlap	64 px (или 10 % от tile-size)	Для точного совмещения линий и подписей между фрагментами. 2–3 px — абсолютный минимум, но на практике для схем лучше 32–64 px.
--format	png	Схемы содержат тонкие линии и текст; PNG исключает артефакты JPEG.
--thumb-size	1024	Достаточно для обзора целой страницы А3/А2 при читаемых крупных блоках.
Зависимости
Требуется только Pillow:
bash
pip install Pillow
Скрипт использует pathlib, работает кроссплатформенно (Linux/macOS/Windows). Перед первым запуском на сотне файлов имеет смысл запустить с --dry-run, чтобы проверить количество фрагментов и не перегрузить диск.
