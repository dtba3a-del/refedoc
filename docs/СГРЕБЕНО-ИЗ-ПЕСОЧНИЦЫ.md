# Сгребено из песочницы перед очисткой

Основание — распоряжение автора: резервная копия профиля Anthropic
гарантированно очищает песочницу; всё ценное переносится в репозитории
проекта, «вспоминать и создавать заново явно записанное» смысла нет.

Дата операции: 2026-09-21. Источник — рабочий каталог сессии
(`scratchpad`), 721 МБ.

## Разделение по зонам

Разделение то же, что и для документов: по правовому классу, а не по
объёму. Настройки и замеры **содержания документа не несут** — они
публичны. Пробные изображения страниц и распознанный текст Е7‑12 несут
содержание документа в состоянии «не установлено» — они в приват.

## Перенесено в публичную зону (`refedoc`)

| Файл | Что это |
|---|---|
| `tools/ocr_settings/ocr_settings.json` | рабочие настройки OCR: выбраны зрением по пробам и **подтверждены перебором**; у каждого параметра названо основание |
| `docs/замер-OCR-2026-09-05/ocr_profile.json` | механический профиль 6 проб из 85 страниц; 4 группы настроек |
| `docs/замер-OCR-2026-09-05/ocr_sweep.json` | замеренный перебор 6 комбинаций: знаков, слов, доля мусора |
| `docs/замер-OCR-2026-09-05/выбор-зрением.json` | что выбрало зрение **до** перебора — видно, где перебор поправил зрение (`rus+eng` → `rus`) |
| `docs/замер-OCR-2026-09-05/настройки-до-разбора.json` | настройки «по умолчанию», от которых считался выигрыш |
| `docs/замер-безопасности-2026-09-05/публичная-зона.json` | скан исполняемого содержимого 21 PDF публичной зоны |

## Намеренно НЕ сгребено: воспроизводится командой

Эти каталоги песочницы — выход инструментов, а не исходное знание.
Команда воспроизведения приложена к каждому; без неё запись была бы
обещанием, а не фактом.

| Что было в песочнице | Команда воспроизведения |
|---|---|
| `INVENTORY.md`, `inventory.json` | `python3 tools/refdoc_inventory.py --from-zones --hash --signature` |
| `dupchk/` (проверка дублей) | то же, с `--signature`; совпадение подписи при разных sha256 = дубль |
| `gpib_out/`, `gpib_out2/`, `test_out/` (нарезка 609 страниц) | `python3 tools/doc_slicer.py slice <файлы> -o <каталог>` |
| `kit/`, `kit2/`, `kit3/` (машинокомплекты) | `python3 tools/make_kit.py <каталог>/index.json -o kit` |
| `kit_test/` (проверка сборки из кусков) | `python3 tools/kit_assembly_test.py` |
| `titles/`, `titles2/` (подбор читаемых имён) | `python3 tools/rename_readable.py --dry-run` |
| `notice_test/` (образец `НАБОР.md`) | побочный выход `doc_slicer.py slice` |
| `guardtest/` (проверка пограничника) | `python3 env/Librarer/hooks/guard.py` на пробном дереве |
| `priv-seed/` (заготовка приватной зоны) | `python3 tools/seed_private.py` |
| `gpib_copy/`, `test_src/`, `e712/` (копии исходников) | исходники на месте в зонах; сверено sha256 — расхождений нет |
| профиль и перебор OCR | `python3 tools/ocr_tune.py profile <pdf> -o ocrprof` и `python3 tools/ocr_tune.py sweep <pdf> -o ocrprof/ocr_sweep.json --page 34` |
| скан безопасности | `python3 tools/pdf_safety.py --root <зона> --out safety.json` |

## Сверка перед очисткой

Перед тем как признать песочницу расходной, сверено, что исходные
документы уже лежат в зонах, а не только в песочнице:

* `E7-12_A1_TO.pdf` — sha256 песочницы `bb2d1fe06df83819…` = `prefedoc` `bb2d1fe06df83819…`
* `E7-12_A2_sh.pdf` — sha256 песочницы `8e7a392817c8cbe5…` = `prefedoc` `8e7a392817c8cbe5…`
* `gpib_copy/` — «не найдено в зонах: 0 из 21»
