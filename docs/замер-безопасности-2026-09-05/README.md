# Скан исполняемого содержимого PDF, 2026-09-05

Основание — распоряжение автора: закладок в файлах мы не предполагаем,
но проверить, что исходник не содержит вредоносное ПО, возможно —
значит, проверяем.

Инструмент — `tools/pdf_safety.py`. Он делит находки надвое:

* **исполняемое** — `/JS`, `/JavaScript`, `/Launch`, `/EmbeddedFile`, `/XFA`;
* **для сведения** — `/OpenAction`, `/AA`: они штатно стоят в обычных
  документах (открыть на странице N, подогнать масштаб) и сами по себе
  признаком не являются.

Разделение введено после ошибки: широкий критерий дал «90 из 123», и
число было доложено неверно как «шесть из 124». Критерий, по которому
срабатывает три четверти обычного корпуса, — не критерий.
