# `refedoc` — справочный корпус профиля

Публичное хранилище **справочного материала** трёх приватных проектов:
PDF и DjVu внешнего происхождения — патенты, стандарты, ГОСТы, datasheet,
руководства, научные статьи, схемы и техописания приборов.

Материал переезжает сюда из репозиториев-источников; на месте остаётся
указатель. Причина переезда одна: справочник тяжёл, меняется он раз в
никогда, а рабочий репозиторий тянет его при каждом клоне.

## Что здесь есть

| Путь | Что это |
|---|---|
| `GPIBNIE7-12/`, `InvesePolar/`, `-Ctpu-bintape-timechannel-/` | материал по репозиториям-источникам, со структурой исходных каталогов |
| [`INVENTORY.md`](INVENTORY.md), `inventory.json` | перепись — **производное**, собирается прогоном |
| [`tools/`](tools/) | инструменты: перепись, нарезка, указатели |
| [`docs/`](docs/) | протокол переноса, замеры, шаблоны |
| [`env/Librarer/`](env/Librarer/README.md) | дом исполнителя: канон, крючки, досмотр границы |

## Это публичная зона

Источники приватны, `refedoc` — нет. Между ними граница, и через неё едет
**только справочный материал**. Стенограммы переписки, журналы сессий,
входящие лотки, ключи и токены сюда не попадают: канон —
[`env/Librarer/RULES.md`](env/Librarer/RULES.md), проверка — крючком,
а не памятью исполнителя.

```bash
bash env/Librarer/hooks/install.sh    # первое, что делается в новом клоне
```

## Инструменты

```bash
python3 tools/refdoc_inventory.py --workspace /home/user --out .   # перепись
python3 tools/doc_slicer.py slice ФАЙЛ -o out --pages 5-16         # нарезка
python3 tools/doc_slicer.py get out/index.json --page 7 --tile 45  # кусок по индексу
python3 tools/doc_slicer.py stats out/index.json                   # замер прогона
```

Зачем нарезка: справочник рассчитан на человека с лупой, а читает его
машина с ограниченным окном. Нарезка даёт **адресацию** — обзор страницы
и отдельный фрагмент вместо страницы целиком. Замер на схеме Е7-12:
обзор плюс фрагмент — **4 %** веса страницы, и надписи читаются.
Подробности и числа — [`docs/ЗАМЕР-2026-09-03.md`](docs/ЗАМЕР-2026-09-03.md).

## Права

Материал в каталогах источников — **сторонний**. Он собран как справочный
корпус и лежит здесь для чтения; лицензии остаются за правообладателями,
и в состав какого-либо приложения этот материал не включается. Инструменты
в `tools/` и `env/` — часть работы профиля.
