# Aletheia — модель, которая не молчит

**Этап 0.0.5.** Локальная языковая модель для LM Studio, обученная на
языке точных вычислений: у каждого значения — класс, у каждого числа —
знаменатель, вместо ложной точности — названный отказ.

Имя — ἀλήθεια, «несокрытость»: то, что не истощается от раздачи.

## Что обещает

* **Точность без предела.** Целые любой ширины, интервалы на сетке,
  сертификат к ответу — не «примерно», а «ровно столько и вот граница».
* **Отказ вместо молчания.** Там, где обычная арифметика возвращает
  `nan` или молча заворачивает, модель называет класс события.
* **Ответ с происхождением.** Каждое утверждение несёт метку: взято из
  источника, из внешней литературы или вычислено здесь.
* **Русский язык как рабочий.** Термины и рассуждение — по-русски, код —
  как есть.

## Как пользоваться

1. Скачать `Aletheia-0.0.5-Q4_K_M.gguf` (Releases; файл собирается из
   частей: `cat Aletheia-0.0.5-Q4_K_M.gguf.part-* > Aletheia-0.0.5-Q4_K_M.gguf`).
2. Положить в каталог моделей LM Studio: `<models>/Aletheia/Aletheia-0.0.5/`.
3. Выбрать модель в LM Studio; системная подсказка — любая, модель
   держит свой стиль сама.

`Q8_0` — вариант выше точности (вдвое тяжелее).

## Основа

База — [Qwen2.5-7B-Instruct](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct)
(Apache-2.0), дообучение — QLoRA (Dettmers et al. 2023) по
[`train_config.json`](train_config.json). Замер хоста перед обучением —
[`probe_host.py`](probe_host.py) (ничего не отправляет, пишет лог рядом).

## Права

База — Apache-2.0 (Qwen Team, 2024). Дообученные веса — стадия 0.0.5
проекта; условия использования — как у базы.
